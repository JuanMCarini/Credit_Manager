\section{Introducción}
\textbf{Credit Manager} es un sistema avanzado para la gestión de carteras de créditos, motores de amortización e ingesta de datos. Permite la administración integral de activos financieros, el cálculo preciso de cuotas y el manejo masivo de carteras y cobranzas.

\section{Características Principales}
\begin{itemize}
    \item \textbf{Motor de Amortización:} Cálculo de cuotas utilizando el Sistema Francés, permitiendo ajustes dinámicos de capital, interés e IVA.
    \item \textbf{Ingesta de Carteras (ETL):} Procesamiento masivo de carteras desde archivos CSV con validación de integridad referencial.
    \item \textbf{Cobranzas Masivas Atómicas:} Soporte para procesamiento de planillas Excel. Ante cualquier inconsistencia, se realiza un \textit{rollback} automático para preservar la integridad de la base de datos.
    \item \textbf{Generación de Punitorios:} Creación automática de créditos independientes por excedentes o sobrantes en los cobros.
    \item \textbf{API y Dashboards:} Interfaz web intuitiva en React para visualizar KPIs, fichas de clientes y reportes de saldos, respaldada por un backend en FastAPI.
\end{itemize}

\section{Arquitectura del Sistema}
El sistema consta de los siguientes componentes principales:
\begin{enumerate}
    \item \textbf{Backend:} Desarrollado en Python utilizando FastAPI y SQLAlchemy. Se encarga de la lógica de negocio, procesamiento financiero y acceso a la base de datos SQLite.
    \item \textbf{Frontend:} Desarrollado en React y Vite. Provee los paneles interactivos y los reportes gráficos (exportables a PDF).
    \item \textbf{Datos:} La base de datos opera sobre SQLite con \texttt{PRAGMA foreign\_keys=ON}. Pandas y NumPy se emplean para cálculos vectorizados y limpieza.
\end{enumerate}

\section{Configuración e Instalación}
\subsection{Requisitos Previos}
Es necesario contar con Python 3 y Node.js para el desarrollo local. También se puede desplegar completamente usando Docker Compose.

\subsection{Configuración del Entorno}
Debe crear un archivo \texttt{.env} en la raíz del proyecto copiando el archivo de ejemplo \texttt{.env.example}. Las variables clave incluyen:
\begin{verbatim}
COMPANY_RAZON_SOCIAL="Empresa Ficticia S.A."
COMPANY_CUIT=30000000000
COMPANY_DIA_CORTE=28
\end{verbatim}

Estos datos se sincronizan bidireccionalmente con la base de datos y pueden ser editados posteriormente desde la interfaz web.

\subsection{Ejecución Local}
Para ejecutar el servidor Backend en modo desarrollo:
\begin{verbatim}
# En Linux/macOS
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
uvicorn src.api.main:app --reload

# En Windows (PowerShell)
python -m venv venv
.\venv\Scripts\Activate.ps1
pip install -r requirements.txt
uvicorn src.api.main:app --reload
\end{verbatim}

\subsection{Ejecución con Docker (Recomendado)}
Para levantar todos los servicios (Frontend, Backend y BD):
\begin{verbatim}
docker-compose -f docker-compose.yml \
  -f docker-compose.dev.yml up -d --build
\end{verbatim}

\section{Uso del Sistema}

\subsubsection{Dashboard}
Permite visualizar un resumen general y detallado del estado de la cartera de créditos a través de múltiples gráficos interactivos y tablas.

\textbf{Interacción con Filtros:}
El panel superior del Dashboard cuenta con una barra de filtros que permiten ajustar los cálculos y la información mostrada. Los filtros disponibles incluyen:
\begin{itemize}
    \item \textbf{Fecha de Corte:} Define la fecha límite para el cálculo de saldos, morosidad y valor actual. Por defecto, toma el último día del mes actual.
    \item \textbf{Tasa de Descuento (TNA):} Tasa Nominal Anual utilizada para descontar los flujos futuros y calcular el Valor Actual de la cartera.
    \item \textbf{Dueños:} Permite seleccionar uno o varios dueños específicos de los créditos. Si se deja en blanco, se incluyen todos.
    \item \textbf{Originadores:} Filtra la cartera según la entidad que originó el crédito. Si se deja en blanco, se incluyen todos.
    \item \textbf{Proyección de Cuotas:} Permite definir la cantidad de períodos y su frecuencia en meses para estimar el flujo de ingresos futuros en el Estado de Situación Patrimonial.
\end{itemize}

Una vez ajustados los parámetros, se debe hacer clic en el botón de aplicar filtros para actualizar toda la información en pantalla. Además, el Dashboard permite exportar todos los gráficos y reportes a formato PDF, conservando los filtros activos.

\subsection{Cartera de Créditos}

\subsubsection{Simular Cuotas}
Herramienta que utiliza el motor financiero de Credit Manager para generar cronogramas de pago bajo el Sistema de Amortización Francés.

Permite ingresar los siguientes parámetros de cálculo:
\begin{itemize}
    \item \textbf{Capital a financiar:} Monto total a otorgar.
    \item \textbf{Plazo (Cuotas):} Cantidad de cuotas del préstamo.
    \item \textbf{TNA c/IVA (\%):} Tasa Nominal Anual.
    \item \textbf{Fecha Emisión y Día Vencimiento:} Fechas clave para el cálculo exacto de días e intereses.
    \item \textbf{Meses de Gracia:} Período inicial donde se pospone el pago.
    \item \textbf{Alícuota IVA:} Porcentaje de impuesto a aplicar sobre los intereses.
\end{itemize}

El resultado es un cronograma detallado que puede exportarse a Excel, mostrando para cada vencimiento el desglose exacto de Capital, Interés, IVA y el Total de la cuota, junto con la sumatoria final de la operación.

\subsubsection{Clientes}
Este submódulo centraliza la gestión de toda la base de datos de clientes, sean personas físicas o jurídicas.

\textbf{Dashboard (Ficha del Cliente):}
Herramienta de búsqueda unificada que actúa como la ficha central del prospecto o cliente. Permite buscar rápidamente por Nombre, DNI o CUIL y visualizar de forma consolidada toda su información: datos personales, estado crediticio, calificación de riesgo (incluyendo reporte del BCRA), detalle completo de la cuenta corriente y KPIs de morosidad.

\textbf{Listado de Clientes:}
Es la vista principal para consultar y administrar la cartera completa. Cuenta con:
\begin{itemize}
    \item \textbf{Filtros y Búsqueda:} Posibilidad de filtrar y ordenar las columnas por CUIL, Documento, Apellido, Nombre, Estado, Email y Teléfono.
    \item \textbf{Acciones Rápidas:} Cada fila incluye una botonera para operar sobre el cliente de forma directa:
    \begin{itemize}
        \item \textbf{Dashboard de Cliente:} Redirige a la ficha del cliente cargando toda su información financiera.
        \item \textbf{Ver Detalles:} Abre una ventana modal con los datos completos del legajo.
        \item \textbf{Créditos:} Redirige al Listado de Créditos aplicando automáticamente un filtro por el CUIL seleccionado.
        \item \textbf{Ver Cuenta Corriente:} Abre un modal para inspeccionar los movimientos de cuenta corriente del cliente sin salir de la pantalla actual.
        \item \textbf{Editar / Eliminar:} Opciones de administración del registro (estas acciones se ocultan por seguridad si el usuario tiene rol de Auditor/Solo lectura).
    \end{itemize}
\end{itemize}

\textbf{Alta de Cliente:}
Formulario para dar de alta nuevos prospectos. El sistema procesa los datos y realiza validaciones automáticas de seguridad, incluyendo un cruce con bases de datos para alertar en pantalla si la persona se encuentra en el RePET (Registro Público de Personas y Entidades vinculadas al Terrorismo).
